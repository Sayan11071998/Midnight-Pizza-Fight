# ***Midnight-Pizza-Fight***
## Midnight Pizza Fight is text based game written with C#
I recently wrapped up the C# Beginner module and whipped up a text-based game called Midnight Pizza Fight 🍕🥊. The story resolves around The Dough Master (chef) 👨‍🍳, who crafts the pizza of his life—probably his magnum opus—only for The Crust Bandit (thief) 🦹‍♂️ to swoop in and steal it. Naturally, a deadly pizza-fueled battle ensues. Who wins? Who gets to the pizza? Only one way to find out. 🎮⚔️

This project was my first dive into C#. Despite being a bit of a C# rookie, I managed to lean on my C++ background to get the job done 💻. Fun fact: C#’s Finalizers took me by surprise. Memory management? Not my problem anymore! 🙌 Thanks, C#.
